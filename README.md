- Added a CSS reset for consistent browser styling.
- Added base typography, spacing and layout rules.

- Styled forms, tables, images and buttons.

### Responsive Design
- Added a tablet breakpoint at 900px.
- Added a mobile breakpoint at 600px.
- Multi-column content changes to a single-column layout on smaller screens.
- Navigation changes to a vertical mobile layout.
- Images and containers use responsive sizing.
- Relative units such as `rem`, `%` and `clamp()` are used for adaptable sizing.
